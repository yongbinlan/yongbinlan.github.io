# 咖啡豆吧台垫｜从商品分析到 AI 视频的内容方法

先弄清商品解决什么麻烦，再把卖点变成能看懂的演示。从商品分析到文案、七组镜头与 AI 视频，这次把中间的思考也展开给你看。

归属：内容与营销增长域 / AI自动化全域内容生产与分发系统 / 站内营销内容生产工厂。
依据：用户商品分析截图、正背侧参考、七组完整稿本和指定30.07秒视频。方法说明为本次材料整理，不是后台执行日志。

## 1. 商品分析｜先把这张垫子认清楚
哪些是产品本身，哪些只是希望视频表现出来的效果？

把正面、背面、侧面资料和商品分析截图放在一起核对。建立外观、规格、使用场景、资料卖点四类信息；每一条保留来源，性能描述另列待实测项。

商品约束卡：45×30cm、棕色长方形软胶、咖啡豆立体纹理、奶油色 Coffee time 字样与咖啡杯图案；正反面必须属于同一件产品。尺寸与材质按提供资料记录。

## 2. 卖点提炼｜从材质参数，翻译成使用价值
消费者为什么要在咖啡机下面多铺一张垫子？

用“商品特征 → 使用收益 → 画面证明”组织卖点。把易清洁放在主线，防滑、沥水、隔热与装饰感作为补充；不把资料上所有优点平均塞进开头。

卖点表达顺序：少擦台面 → 杯具放置与沥水 → 沾水沾酱油后的清洁 → 热饮与厚度 → 咖啡角搭配。安全无异味等资料说法不凭 AI 画面下结论。

## 3. 痛点分析｜从“产品很好”回到日常麻烦
观众会在哪个生活瞬间觉得“我也需要”？

按“谁、什么时候、遇到什么麻烦、希望得到什么结果”拆解。主场景锁定家里常做咖啡的人，优先讲滴漏弄脏台面、洗杯后的水珠和杯具摆放。

开场不是罗列参数，而是白色台面上的咖啡滴漏。后续每个问题都安排对应演示，让口播有具体画面承接。

## 4. 热门文案梳理｜借表达结构，落回本品事实
一句生活化的话，怎样带出一个购买理由？

在提供的稿本中标记“使用体验开场 → 麻烦被解决 → 连续演示 → 质感与搭配 → 轻量推荐”的段落职责。保留“费劲巴拉”“你看”“整这么一个”等朋友式表达，再逐句匹配当前商品的画面。

形成文案结构卡与口播—镜头对应表。本次收到的是分析截图、稿本和成片，未提供热门文案的原链接或热度数据；此处展示结构梳理，不认定这条文案已成为爆款。

## 5. 七组镜头｜把每个卖点变成可执行动作
镜头里究竟要发生什么，观众才能看懂？

把完整设计稿拆成七组、17个动作段。每段绑定原句、景别、动作顺序、物体承托关系和可见结果；等待、慢扫、拉远及厚度对比单独标记，不用跳切替代。

可执行镜头表：滴漏与擦拭、放杯提杯与翻角、防滑与沥水、水珠酱油与热饮、厚度对比、咖啡角全景、生活化收尾。下方可逐组查看原口播与动作。

## 6. 生成约束｜先锁商品、人物和场景，再交给 AI
怎样减少换脸、产品变形和动作不合常理？

将正反面产品参考、人物身份参考、服装配饰和厨房场景分开描述。统一9:16画幅、人物气质、自然光和同一女性声音；把不能穿模、污渍不能凭空消失、不能放大垫面等要求写成具体限制。

形成“固定商品与人物条件 + 分组动作 + 同步口播 + 逐项检查”的生成任务稿。本次展示已有生成产物，不推断未提供的模型、参数或生成次数。

## 7. 视频产物｜把成片放回稿本旁边检查
视频生成出来了，哪些地方还要回看？

检查产品图案、正反面连续性、人物一致性、口播与动作对应、污渍擦除和器具承托。将稿本要求与实际成片分开记录，不能只凭“生成成功”就判定全部完成。

已有30.07秒、1080×1920、30fps的 AI 视频样例。本页保留原速与原声，使用适合网页播放的同内容版本；现有成片含字幕，不能视为“无字幕、完整七组设计稿”的逐镜验收通过。

## 8. 方法沉淀｜让下一件商品能复用思路
换一个商品，哪些可以复用，哪些必须重做？

可复用的是痛点提问方式、段落职责、演示设计和检查清单；必须重做的是商品事实、性能依据、适配场景和口播。按“商品事实—场景痛点—买点—句子—动作—产物”保留关联。

本页沉淀完整案例说明与可下载的方法档案，可作为内容工厂后续 RAG 入库的素材。本次不宣称已执行知识库写入或检索命中；发布后的播放、停留与成交反馈仍待记录。

## 痛点、购买理由与演示设计

- 咖啡滴漏，台面要反复擦 → 让清理更省事 → 滴漏 → 铺垫 → 湿抹布擦除；酱油接触 → 擦除 → 看结果（第1、4组）
- 杯具易滑，洗完有水珠 → 摆放更稳，兼顾沥水 → 放杯轻推；玻璃杯倒扣 → 等待 → 拿起（第2、3组）
- 热饮摆放、薄垫质感的顾虑 → 隔热与厚实感 → 奶壶放下 → 等待 → 拿起；同角度捏边对比（第4、5组）
- 实用用品不好搭配咖啡角 → 功能之外，也要好看 → 纹理慢扫 → 器具搭配 → 拉远看整体（第5、6、7组）

## 七组完整设计稿
全部17段口播与动作按用户原稿保留。此为设计稿，不代表现有30秒样片已全部兑现。

### 第1组｜咖啡滴漏、铺垫与台面清洁
明亮清晰，特写突出污渍与清洁效果，生活感强。

1. 特写厨房白色台面。咖啡机滴漏口滴出棕色咖啡，几滴咖啡渍在台面上蔓延。画面出现时立即开始口播。
   口播：“自从我家咖啡机下面有了这个垫子，”

2. 切中景。人物将咖啡豆吧台垫平整铺在咖啡机下方，调整位置，镜头跟随手部动作。
   口播：“就再也不用费劲巴拉地收拾了。”

3. 接近景。人物用湿抹布擦拭之前的咖啡渍，污渍被擦掉，台面恢复洁净。
   口播：“它这个不仅防水防油，”

执行要点：铺垫时咖啡机需要被合理挪开再放回，不能让垫子穿过机身；咖啡渍随抹布擦拭被带走，不能凭空消失。三段口播自然连贯，不增加段间空白。

### 第2组｜正面细节、杯底与背面展示
暖光氛围，特写展示产品细节，温馨自然。

1. 特写聚焦垫面，棕色咖啡豆图案清晰，中间“Coffee time”字样可辨，暖光呈现产品质感。
   口播：“咖啡制作完之后啊，”

2. 接近景。人物将绿色手柄咖啡杯放在垫子上，再拿起。拿起时切到杯子底部特写，杯底干净无水渍。
   口播：“你看这个杯子底儿，是不是一点都不湿？”

3. 接特写。人物捏起垫子一角，展示与图片2一致的棕色背面。
   口播：“而且你看它这个背面是这种橡胶的，”

执行要点：用放杯、提杯和翻角动作衔接镜头，不加入额外摆拍。翻角时其余部分自然贴在台面上，产品正反面连续一致。

### 第3组｜防滑与沥水演示
动态展示，镜头聚焦防滑与沥水功能，直观生动。

1. 近景。人物将咖啡杯放在垫子上，用手指轻推杯身，杯子纹丝不动。
   口播：“所以杯子放上去就不会打滑。”

2. 切中景。人物将刚冲洗的玻璃杯倒扣在垫子上，几秒后拿起，镜头特写杯底，展示水珠已沥干的状态。
   口播：“平时把它垫在洗好的杯子下面，还能当个沥水垫用。”

执行要点：保留倒扣、等待和拿起的顺序，等待期间继续对应口播。水珠自然向下流动，不通过水珠凭空消失或将垫子变成吸水海绵来表现沥水。

### 第4组｜水珠、酱油清洁与隔热
细节特写，突出耐用性与易清洁特点。

1. 特写。一滴水珠滴落在垫面上，水珠保持完整球形滚动。
   口播：“你看，水滴上去，”

2. 接特写。一滴酱油滴在垫面上，人物用纸巾轻轻一擦，酱油渍被完全擦除，表面洁净如初。
   口播：“包括酱油滴上去，都完全不会渗进去，一擦就干净了。”

3. 切中景。人物将冒着热气的奶壶放在垫子上，几秒后拿起，镜头给到奶壶下方对应的垫面区域，表面无痕迹。
   口播：“而且它还能隔热，”

执行要点：水珠贴着垫面运动，不悬浮。酱油擦拭展示接触、带走和擦后状态；奶壶由台面承托，放置与拿起动作连贯。保留原稿要求的等待时间，口播同步进行。

### 第5组｜厚度对比与产品质感
对比展示，突出厚实感与颜值。

1. 近景。人物将咖啡豆吧台垫与普通薄款餐垫并排举起，用手指捏起边缘进行对比，咖啡豆吧台垫明显更厚实。
   口播：“所以刚做好的热饮也能直接放上去。”

2. 接特写。镜头缓慢扫过咖啡豆吧台垫表面，咖啡豆图案与“Coffee time”字样清晰立体，暖光下呈现高级质感。
   口播：“虽然价格便宜，但你看它这个厚度，完全不是那种廉价的东西。”

执行要点：对比时两张垫子的观察角度相近，不通过改变产品比例夸大厚度。扫镜与口播同时进行，保留缓慢扫过的动作，不额外增加静物停留。

### 第6组｜咖啡角搭配与全景展示
温馨装饰场景，突出产品美观性。

1. 中景。人物将垫子铺在台面上，旁边摆放咖啡机、绿色杯子、黄色奶壶和金属手冲壶。镜头从左至右缓慢扫过，展示垫子融入环境。
   口播：“往台面上一放，颜值也挺高的。”

2. 接全景。镜头缓慢拉远，展现整洁有格调的咖啡角。垫子上摆放咖啡杯、奶壶和手冲壶，营造温馨精致的氛围。
   口播：“这种垫垫啊，平时放在桌子上装饰一下，或者拿来当个桌垫都可以。”

执行要点：扫镜和拉远分别承接对应口播，不增加无声空镜。器具尺寸和摆放符合45×30cm垫面的实际空间，不让器具穿插，不为容纳器具放大产品。

### 第7组｜生活化体验与购买引导
轻松自然，亲切真实。

1. 近景。人物将粉色咖啡杯放在垫子上，再拿起杯子，将杯口凑近闻一下，露出满意微笑。
   口播：“如果你们家里边也经常做咖啡，”

2. 切中景。人物整理台面上的咖啡器具，最后将垫子铺在台面中心，双手轻抚垫子边缘，看向镜头。
   口播：“真的可以整这么一个回去试一试。”

执行要点：闻杯时对应声音作为画外音延续，不要求人物同时闻杯和张口说话。整理与铺垫过程符合物体承托关系，移动垫子前移开其上的器具。结尾在人物、产品和咖啡角清晰可见的画面自然结束，不追加新台词或标语。

## 全片约束
查看全片人物、场景、节奏与声音要求
商品：
45×30cm棕色长方形软胶咖啡豆吧台垫；保留咖啡豆立体纹理、边框、中央奶油色“Coffee time”与咖啡杯图案，正反面连续一致。
人物：
稿本指定柚子，同一面容、棕色短卷发、白色无袖上衣、简洁金色手镯与戒指、红色指甲。人物参考仅用于身份，不继承背景；本页未另行公开人物参考图。
场景：
真实家庭厨房咖啡角，白色台面、温暖木色柜体、小型咖啡机和日常杯具。明亮自然室内光与柔和暖色侧光，干净构图，不做豪华展厅、不用浓重滤镜与过度磨皮。
节奏：
直接进入咖啡滴漏，口播与演示同步，不新增片头。不能改写、删减或合并口播，不遗漏动作、演示与对比；慢扫、拉远、等待几秒保留，不能用闪切、倍速代替，不强制压到30秒。
声音与文字：
同一女性自然普通话，露脸口型同步，特写延续画外音；保留滴落、杯具、擦拭等动作音，低音量轻快暖色背景音乐。稿本要求不加字幕、跳字、价格贴纸或额外标语，产品自带文字保留。
