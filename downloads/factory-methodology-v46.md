# 站内营销内容生产工厂 · RAG 方法论

归属：内容与营销增长域 → AI自动化全域内容生产与分发系统 → 站内营销内容生产工厂。

适用范围仅限本工厂。

采集 → 分析 → 拆解 → 沉淀 → 复用 → 反馈修订。

## 实际依据

同一知识库组织视频案例、通用框架、策略组件、细分类目模板。以关键词、类目、购买任务和证据状态检索；来源主库与派生视图区分。任务中商品事实独立，不由参考案例补齐。

S：沉淀与新选题；A：限定对象替换；B：原片拍摄方案；P：商品驱动策划。用户主动发起创作任务，不由学习任务自动开启制作。

实际检索例：FW-MOTIVATION-CONTRAST-001、CT-EYE-COOLING-MOTIVATION-001、CT-CHARGER-MOTIVATION-001，均为v1候选；普遍营销效果未建立。

## 本工厂应用逻辑

本地方法与检索实践

- **来源证据：** 用户主动给原片或商品事实；学习任务提供来源案例
- **知识资产：** 视频案例、通用框架、策略组件、细分类目模板
- **拆解与判断：** 先解释开头、中段、证明与结尾各自职责，再提炼可替换槽位与适配条件
- **复用与执行边界：** S学习创作、A限定替换、B原片拍摄、P商品策划按不同检索边界执行
- **交付物：** 带来源的框架与模板、按任务交付的策划/脚本/拍摄方案
- **检验方法：** 查库与展开来源核对；脚本查商品事实；制作时另验实际成片
- **反馈去向：** 采用记录绑定知识版本和具体产物；偏好、制作与市场反馈分开修订
